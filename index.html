Getting Started

Setting up Wi-Fi

The very first time you power it on — or any time after a factory reset — the device creates its own Wi-Fi network so you can connect it to your home network.

📶 First boot / setup mode

  1. Power on the device. It shows a screen with a network name and an IP address.
  2. On your phone or computer, connect to the Wi-Fi network named Klaude-Buddy-Setup.
  3. Open a browser and go to 192.168.4.1.
  4. Enter your home Wi-Fi name and password, then save.
  5. The device restarts and joins your network automatically.

The Control Panel

The Dashboard

Once connected to your Wi-Fi, everything is configured from a web dashboard — no app to install. Open it from any browser on the same network.

🌐 Reaching the dashboard

Visit http://klaude-buddy.local, or the device's IP address shown on its Info screen. The dashboard has tabs across the top: Status, Wi-Fi, Channels, APIs, Shortcuts, Pet, You, and Device.

The Channels tab is where you turn each screen below on or off, and choose how long the display lingers on each one before rotating to the next.

🔌 Custom APIs APIs tab

Connect up to 8 of your own APIs — anything that returns JSON. For each one you set a title, the endpoint URL, an optional auth header, and how often it refreshes (from every 5 minutes up to once a day). Then pick which values to show by pointing at a field inside the response, e.g. data.visits.daily.

Each API supports up to 24 fields, shown 4 per page (so up to 6 pages), automatically paging through with its own turn on screen — no scrolling or tapping needed.

🔗 Shortcuts Needs companion app

Up to 45 one-tap shortcuts to your favorite links, shown 15 per page (so up to 3 pages) — swipe to move between pages. This needs a small companion app running on a computer connected to the device by USB — tapping a shortcut tells that computer to open the link in its browser.

A brand-new device comes with one shortcut already loaded — the >_< icon, which opens the device's own dashboard in your browser. Edit or delete it like any other shortcut; it's just a convenient default, not something special.

💻 The companion app For Shortcuts & Clipboard

A small desktop app that sits in the background on a computer connected to the device by USB. It listens for taps on the Shortcuts and Clipboard screens and acts on them — opening a link in your browser, or simulating a keyboard shortcut. It never runs arbitrary commands, only those two specific, safe actions.

The device needs to stay physically plugged into that computer by USB the whole time — Shortcuts and Clipboard talk to the app over that same USB cable, not over Wi-Fi or the network. If you unplug it, or plug it into a different computer, only that connected computer's companion app (if running) will respond to taps.

⬇️ Download for Windows  ·  🍎 Download for Mac

Windows setup:

  1. Run KlaudeShortcutsSetup.exe and follow the installer (Next → Install → Finish).
  2. It starts automatically once installed, and sets itself to launch every time you log in — no need to open anything by hand afterward.
  3. Already have an older version installed? Just run the new installer over it — it upgrades in place, no need to uninstall first.
  4. To remove it later: Settings → Apps (or Control Panel → Programs), find Klaude Shortcuts, and uninstall — it's a proper entry, not just a loose file.

Mac setup: unzip the download first — you'll get KlaudeShortcutsInstaller.pkg and a separate uninstaller. The .pkg isn't signed by a registered Apple developer yet, so macOS blocks it the first time; this is a one-time step.

  1. Double-click KlaudeShortcutsInstaller.pkg.
  2. If you see "cannot be opened because it is from an unidentified developer": open System Settings → Privacy & Security, scroll down, and click Open Anyway next to the message about the blocked installer (confirm with your password or Touch ID). Then double-click the .pkg again.
  3. If instead it says the installer "is damaged and can't be opened", that's Gatekeeper reacting to the browser's download quarantine flag, not an actual broken file — open Terminal and run xattr -cr ~/Downloads/KlaudeShortcutsInstaller.pkg (adjust the path if you saved it elsewhere), then open it normally.
  4. Follow the installer (it'll ask for your Mac password since it installs into Applications). It installs the app, sets it to launch on login, and opens it once automatically.
  5. Separately from the step above, it needs one more permission for Copy/Paste to work: go to System Settings → Privacy & Security → Accessibility (a different tab from the one used to unblock the installer) and enable the checkbox next to KlaudeShortcuts. Shortcuts — opening links — works without this; only Clipboard needs it.
  6. To remove it later, double-click "Uninstall KlaudeShortcuts.command" (included in the same zip) — no Terminal commands needed.

Either platform, once installed: plug the device in by USB-C, open the Shortcuts screen on it, and tap one — a browser tab should open with that link, coming to the front even if you were doing something else on the computer.

🙋 Needs You Channels tab · Needs companion app once

Answer a blocked Claude Code permission prompt with a tap on the device — over Wi-Fi, no USB cable needed at the moment it happens. When a PreToolUse hook fires, the display interrupts whatever screen was showing with the tool name and a short summary, plus a quick brightness flash so it's hard to miss.

Tap Approve or Deny to answer directly. The ✕ in the corner dismisses the popup without deciding — the device goes back to normal, and Claude Code falls back to asking you in the terminal as usual.

Setup is one-time and mostly automatic: if you already have Claude Code configured on the same computer running the companion app (see Shortcuts below), the app registers the hook by itself the first time it opens — no separate script to run. Then just turn on Needs You in the dashboard's Channels tab.
