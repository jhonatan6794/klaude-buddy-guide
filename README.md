# Klaude Buddy — User Guide

Live guide: **https://jhonatan6794.github.io/klaude-buddy-guide/** (enabled via GitHub Pages)

A screen-by-screen walkthrough for setting up and using the device. To finish it:

1. Drop screenshots into `assets/screens/` — see the checklist in that folder for exact filenames.
2. Add your demo video: open `index.html`, find the `video-slot` block in the hero section, and replace the placeholder comment with a YouTube/Vimeo `<iframe>` embed.
3. Add your store link: find `<a class="buy-btn" href="#">` in `index.html` and replace `#` with the real purchase URL.

No session keys, API keys, or other secrets belong in this repo — it's public.
